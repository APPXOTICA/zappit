# 태국어(th) 번역 검토 결과

가장 큰 문제는 결제·체험 문구였다. Pro preview가 키마다 “การทดลองใช้ Pro”, “ทดลองใช้ Pro”, “การทดลองใช้ Pro ฟรี”로 제각각이었고, 스토어 체험 알림 제목이 Pro preview와 거의 같은 말이었으며, “สโตร์”(스토어)·“บัญชีสโตร์”(스토어 계정) 같은 내부 용어와 “No credit card required” 직역이 남아 있었다. 그 밖에 “Unleash”·“No thanks” 같은 직역, 챕터를 Episodes와 헷갈리는 “ตอนย่อย”로 옮긴 것, 폰에 보이는 “이 페이지”·“그 폰”처럼 모호한 지시어, 버튼 이름 따옴표 불일치를 고쳤다. 태국어는 꾸미는 말이 뒤에 오므로 “ไม่จำกัด”(무제한)은 뒤에 두고, “~ได้ไม่จำกัด”(무제한으로 ~할 수 있음) 구조로 혜택을 분명히 했다.

용어 결정: Pro preview = “ช่วงทดลองใช้ Pro ฟรี” / “ทดลองใช้ Pro ฟรี”(항상 Pro + ฟรี), 스토어 체험 = “การทดลองใช้ฟรี”(Pro를 붙이지 않음). 따옴표는 태국어 관례인 “ ”로 통일. 문장 끝 마침표는 태국어 관례대로 쓰지 않고 문장 사이를 공백으로 구분(기존 파일과 동일).

## 확인이 필요한 점

- **chapters(“บท”), selectVideoInBrowser** 는 화면·블록 제목이라 menu-name: yes로 표시했다. 웹 가이드·FAQ 태국어 번역(`zappit_web/src/lib/i18n/messages/`)에 같은 말이 있으면 맞춰야 한다. 이번 작업에서는 웹 번역 파일이 없어 대조하지 못했다.
- **chapters “บท”**: YouTube 태국어 UI의 챕터 명칭은 태국어 YouTube 가이드 글(“บทวิดีโอ”, “บท”)로 확인했다. Google 고객센터 태국어 페이지는 이 환경에서 열리지 않아 공식 화면 문구로는 확인하지 못했다.
- **바꾸지 않았지만 확인이 필요한 YouTube·Netflix 명칭**(공식 화면으로 확인하지 못함): ytHistory “ประวัติ”(YouTube 태국어는 “ประวัติการเข้าชม”일 수 있음), ytCourses “คอร์ส”(“หลักสูตร”일 수 있음), skipIntro “ข้ามช่วงเปิด”(Netflix 태국어 버튼은 “ข้ามอินโทร”일 수 있음). 태국 계정 화면을 보고 다르면 고치는 것을 권한다(모두 menu-name 해당).
- **learnMore “ดูข้อมูลเพิ่มเติม”** 은 태국 앱(Google 등)의 표준 표현이라 바꾸지 않았다. 한국어처럼 바꿀 필요가 없는 경우다.
- **proPreviewEndedMessage**: 태국어에서 “ขอบคุณที่ลองใช้”(써 봐 주셔서 감사)는 어색하지 않고 “ลองใช้”는 유료 이용으로 읽히지도 않는다. 그래도 한국어 결정과 맞춰 질문형(“Zappit Pro เป็นอย่างไรบ้าง”)으로 바꿨다. 감사 인사를 원하면 되돌려도 된다.
- **trialReminderNotificationTitle** 에서 “Zappit Pro”를 뺐다(알림에 앱 이름이 함께 보이고, Pro preview 용어와 겹치지 않게 하려고). 원문처럼 상품명을 남기려면 “การทดลองใช้ฟรีของ Zappit Pro รายปีใกล้สิ้นสุดแล้ว”처럼 “รายปี”(연간)를 붙이는 방법이 있다.
- **tellAFriend “บอกเพื่อน”** 은 직역에 가깝지만 틀린 말은 아니라 그대로 두었다. 더 흔한 표현은 “แนะนำให้เพื่อน”이다(바꾸면 menu-name 해당).
