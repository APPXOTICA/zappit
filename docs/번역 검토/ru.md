전반적으로 문법과 말투(вы, 정중한 존댓말)는 안정적이었지만, 결제 문구에 'магазин'(스토어)·'аккаунт магазина' 같은 내부 용어가 그대로 쓰였고, Pro preview('Пробный доступ', 'Пробный Pro')와 스토어 무료 체험('бесплатный период', 'пробный период')의 용어가 섞여 두 개념이 헷갈릴 수 있었다. 이를 Pro preview = **'Бесплатный доступ к Pro'**, 스토어 체험 = **'(бесплатный) пробный период'**로 나눠 통일했다. 그 밖에 기능 목록의 어순('… без ограничений' → 'Безлимитный …'), 폰에서 보이는 모호한 지시어('эту страницу', 'того телефона'), 직역·명령형으로 오해되는 표현을 고쳤다.

## 확인이 필요한 점

- **용어 결정**: Pro preview를 'Бесплатный доступ к Pro'(Pro 무료 이용), 스토어 체험을 'пробный период'(체험 기간)로 정했다. 러시아 App Store·Google Play가 구독 체험을 'пробный период'라고 부르므로 이를 스토어 쪽에 남기고, Pro preview에서는 '체험(пробный)'을 빼서 구분했다. 웹 번역(`zappit_web/src/lib/i18n/messages/`)에 Pro preview 관련 문구가 있다면 같은 용어로 맞춰야 한다.
- **startFreeTrial**(menu-name: yes): Pro 화면 버튼 'Начать бесплатно' → 'Начать пробный период'. 웹 가이드·FAQ가 이 버튼 이름을 인용한다면 동기화가 필요하다.
- **cancelAnytime**: 한국어처럼 해지 위치를 말하려면 'в настройках подписок'(구독 설정에서)를 붙일 수 있지만, 문장이 길어지고 iOS·Android 경로가 달라 '언제든 해지 가능'만 남겼다. 위치를 넣길 원하면 알려 달라.
- **freeTrial**(체험 기간을 모를 때의 연간 요금제 배지): 'Пробный период'로 바꾸면서 '무료(Бесплатный)'가 빠졌다. 'Бесплатный пробный период'는 배지에 길어서 뺐는데, 공간이 충분하면 넣는 편이 더 명확하다.
- **일 수 표기**: `proPreviewStarted`, `freeTrialDays` 등은 영어 원문에 복수형 ICU가 없어 'дн.', 'нед.' 같은 약어를 그대로 두었다. 러시아어로 '7 дней'처럼 쓰려면 영어 원문에도 plural을 두는 편이 안전하다.
- **browsersDisconnectedBody**: 제목의 `{browsers}`가 여러 개일 수 있지만 영어 원문이 'it'이라 단수('К нему')를 유지했다.
