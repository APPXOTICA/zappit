# 우크라이나어(uk) 번역 검토 결과

전체 347개 문구 중 26개를 고쳤다. 기본 번역 품질은 좋았지만, 결제 문구에 'магазин'(스토어)·'обліковий запис магазину'(스토어 계정) 같은 내부 용어가 남아 있었고, 스토어 무료 체험 문구 일부('Почати безкоштовно', 'пробний період')가 Pro 무료 체험(Пробний доступ до Pro)이나 완전 무료와 헷갈릴 수 있었다. 그 밖에 keep·use again 같은 직역 동사, 폰 앱에서 모호한 '이 페이지'·'그 폰', '무제한'이 뒤로 밀린 기능 목록, 러시아어식 구문('Немає що')과 비규범 속격('телефона')을 고쳤다.

## 확인이 필요한 점

- **웹 번역 동기화:** menu-name이 yes인 `startFreeTrial`(Почати безкоштовний період), `noThanks`(Ні, дякую), `phoneName`(Назва телефону), `pickVideosWithPro`는 웹 가이드·FAQ(`zappit_web/src/lib/i18n/messages/`)의 우크라이나어가 인용하고 있으면 같이 고쳐야 한다. 이번 작업 환경에는 웹 메시지 파일이 없어 직접 대조하지 못했다.
- **`learnMore`, `proPreviewEndedMessage`는 그대로 두었다.** 'Докладніше'는 우크라이나어 앱의 표준 Learn more 버튼이고, 'Дякуємо, що спробували Zappit Pro!'는 우크라이나어권에서 자연스러운 표현이며 'спробували'(써 보셨다)에 유료 이용 뉘앙스가 없다고 판단했다. 한국어처럼 질문형("Як вам Zappit Pro?")으로 바꾸길 원하면 알려 달라.
- **YouTube 메뉴 이름:** `ytExplore`(Огляд), `ytLive`(Наживо), `ytHype`(Хайп)가 YouTube 우크라이나어 화면의 실제 이름과 같은지 확인하지 못했다(Explore가 'Навігатор'일 가능성). 우크라이나어 YouTube 화면으로 한 번 확인이 필요하다.
- **`proPreviewStarted`의 '{days} дн.':** 문장 안 약어는 다소 딱딱하지만, 영어 원문이 복수형(ICU plural)이 아니라서 약어로 격 변화를 피한 원래 방식을 유지했다.
