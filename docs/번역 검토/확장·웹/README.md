# 확장·웹 번역 검토 결과 (21개 언어)

`docs/번역 가이드.md` 기준으로 확장(`zappit_extension/public/_locales`)과 웹(`zappit_web/src/lib/i18n/messages`)을 언어별 전문가 에이전트가 검토·수정하고 다시 검수했다. 앱 검토 결과(`docs/번역 검토/<언어>.md`)를 기준으로 Pro preview 용어와 메뉴 이름을 맞췄다. 앱 문구 중 확장 라벨을 가리키던 것('Reset' 등, 확장이 영어뿐일 때 쓴 것)은 확장의 번역 라벨로 바꿨다. 영어 원문은 바꾸지 않았다.

## 여러 언어에 공통으로 남은 확인 사항

- **브라우저·OS 화면 문구:** 웹 FAQ(a8~a13)가 인용하는 Chrome 권한 경고, Chrome 사이트 액세스 메뉴, Safari·iOS·Android 설정 이름은 거의 모든 언어에서 실제 화면과 대조하지 못해 원래 번역을 유지했다. 출시 전에 브라우저·OS 언어를 바꿔 실제 문구와 맞춰 본다.
- **Tutorial과 Guide 이름:** 여러 언어(cs, pl, ru, tr, zh_Hant)에서 앱 More의 Tutorial 이름과 그 메뉴가 여는 웹 가이드 제목이 다르다. 영어도 Tutorial/Guide로 달라 그대로 두었다. 통일하려면 영어부터 정한다.
- **FAQ 표기:** 웹 상단 메뉴는 짧은 'FAQ', 앱과 FAQ 페이지 제목은 그 언어 표현인 경우가 있다(pl, uk, vi 등). ko·ja는 앱과 같게 바꿨다(헤더가 좁아 줄바꿈되면 되돌릴 것).
- **랜딩 슬로건:** hu, th, tr, zh_Hans는 웹 'Kill the mouse.' 번역을 앱 온보딩 슬로건(`obAnimTagline`)과 같게 맞췄다. 다른 쪽을 원하면 앱과 함께 바꾼다.
- **`landing.snack.speed`의 `{speed}` 형식:** 숫자만 들어가는지 '1.5×'처럼 기호까지 들어가는지에 따라 zh·ko 표현이 달라진다.

## 언어별 특이 사항

- **ko:** 웹 전체를 앱과 같은 -요체로 바꿨다(약 45개). 법적 문구인 `footer.trademark`만 -ㅂ니다체로 둘지 정해야 한다. `pairPhoneLimit`은 소유자가 고친 문장에서 'Reset'만 "‘설정’의 ‘초기화’"로 바꿨다.
- **pt:** 앱·웹은 브라질 포르투갈어 하나뿐이라, 포르투갈 사용자는 확장에서는 유럽 용어(telemóvel, Definições), 앱·웹에서는 브라질 용어를 보게 된다.
- **ar:** RTL 문단에서 `[ ]` 괄호가 뒤집혀 보이는 문제를 보이지 않는 LTR 격리 문자로 감쌌다. 사이트에서 실제로 맞게 보이는지 확인한다.
- **hi:** `pairPhoneLimit`에 'Settings' 경로를 넣었다(영어 원문에는 없음). ko도 같은 방식이다. 다른 언어도 경로를 넣을지 정한다.

자세한 키별 수정 전·후와 결정이 필요한 점은 각 언어 보고서(`<언어>.md`)에 있다.
