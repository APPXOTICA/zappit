# 일본어(ja) 확장·웹 번역 검토 보고서

확장 32개 중 7개, 웹 문구 중 39개를 고쳤고, 앱 파일은 교차 참조 키 1개를 고쳤습니다. 웹은 Pro preview를 영어 "Pro Preview"로 두고 "クレジットカード不要" 관용구를 직역한 부분, 데모 스낵바·접근성 라벨이 앱 용어("区間リピート", "リピート オン", "最初から再生", "全画面表示")와 다른 부분을 주로 고쳤습니다. 확장은 팝업을 그린 앱 온보딩 애니메이션 문구와 맞추고("接続済みのスマホ", "後にコードを更新"), 어색한 직역을 고쳤습니다.

## 확인이 필요한 점

- **확장 phoneConnected:** 섹션 제목을 앱과 같이 "接続済みのスマホ"로 바꾸면서, 지금 열려 있는 폰 표시는 "接続中"으로 바꿨습니다. 앱 상태 표시(connected "接続済み")와는 다른 말이지만 의미(지금 연결 중)가 달라 일부러 구분했습니다.
- **스낵바의 "字幕 オン"처럼 띄어 쓴 표기:** 앱 파일의 확정 표기를 따랐습니다. 일본어로는 "字幕オン" 또는 "字幕をオンにしました"가 더 흔하므로, 바꾸려면 앱과 웹을 함께 바꿔야 합니다.
- **Safari·Chrome 화면 이름(faq.a9·a10·a13):** "Webサイトを編集…", "ほかのWebサイトを閲覧中", "すべてのWebサイトで常に許可", "サイトデータの読み取りと変更" 등은 고치지 않았습니다. Apple 공식 일본어 도움말을 이 환경에서 열 수 없어 실제 화면과 글자 단위로 대조하지 못했습니다. 일본어 macOS·Chrome에서 한 번 확인해 주세요.
- **common.nav.faq:** 메뉴를 "よくある質問"(6자)로 바꿨습니다. 헤더 폭이 좁아 줄바꿈되면 "FAQ"로 되돌려도 됩니다(그때 helpBody·helpCta도 함께).
- 검증: `validate2.py ext:ja web:ja`, `validate.py ja` 모두 누락·추가 키와 placeholder 문제 없음. extDescription은 33자.
