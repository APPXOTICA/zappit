# 태국어(th) 확장·웹 번역 검토 결과

확장은 대체로 자연스러웠고, 앱 검토에서 고친 시간 표현(“โค้ดใหม่ในอีก”) 하나만 맞췄다. 웹은 FAQ의 Pro preview가 영어 “Pro Preview”로 남아 있던 것, “No credit card” 직역, “ซิงค์”(sync) 같은 기술 용어, 데모·가이드가 인용하는 앱 버튼 이름(전체 화면, 처음부터 재생, 구간 반복, 앞으로 10초, 약관 이름 등)이 앱과 다르던 것, Chrome 메뉴 이름이 실제 Chrome 태국어 화면과 다르던 것을 고쳤다. 앱은 “Reset”을 확장의 태국어 라벨 “รีเซ็ต”(“การตั้งค่า” 안)로 바꾸고, 온보딩 애니메이션의 팝업 제목을 확장 제목과 맞췄다.

Chrome 문구는 Chromium 원본 번역 파일(`generated_resources_th.xtb`)에서 메시지 ID로 확인했다: “อ่านและเปลี่ยนแปลงข้อมูลทั้งหมดของคุณในทุกเว็บไซต์”(설치 경고, 기존 번역과 같음), “ส่วนขยายนี้อ่านและเปลี่ยนข้อมูลเว็บไซต์ได้”, “ในเว็บไซต์ทั้งหมด”, “สิทธิ์เข้าถึงเว็บไซต์”, “รายละเอียด”.

## 결정이 필요한 점

- **Safari 메뉴 이름**(faq.a9Steps, a9Note, a13Points[1]: “แก้ไขเว็บไซต์…”, “เมื่อเยี่ยมชมเว็บไซต์อื่น”, “อนุญาตเสมอในทุกเว็บไซต์”, “ส่วนขยาย”)과 **Android 권한 이름**(“อนุญาตเฉพาะขณะใช้แอป”)은 원본 번역 파일로 확인하지 못해 그대로 두었다. 태국어로 설정한 Mac·Android 화면과 한 번 대조하는 것을 권한다.
- **common.launch** “เปิดตัวต้นเดือนธันวาคม 2026”: 태국은 불기(พ.ศ. 2569)를 많이 쓰지만 IT 서비스 공지는 서기도 흔하다. 그대로 두었다.
- **landing.title “ลาก่อนเมาส์”**(안녕, 마우스): 앱 슬로건에 맞췄다. 원래 웹의 “วางเมาส์ลงได้เลย”(마우스를 내려놔도 돼요)를 선호하면 앱 obAnimTagline도 같이 바꿔야 한다.
- **“ไม้บรรทัด”(자)**: 프레임 다이얼을 가리키는 웹 문구(hint4, f5Body, f5Tip)는 영어 “ruler”를 그대로 옮긴 말이지만 화면 모양과 맞아 이해에 문제가 없어 두었다.
- 반복 기호 “ๆ” 띄어쓰기가 웹(“เรื่อย ๆ”)과 앱(“เรื่อยๆ”)에서 다르다. 둘 다 쓰이는 표기라 파일마다 기존 방식을 유지했다.
