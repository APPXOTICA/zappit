# 베트남어(vi) 확장·웹 번역 검토 결과

확장 1개, 웹 27개, 앱 교차 참조 1개를 고쳤다. 웹 FAQ가 Pro preview를 영어 "Pro Preview" 그대로 쓰고 "Không cần thẻ tín dụng"(카드 필요 없음) 관용구를 직역하고 있어서, 앱 용어 "Trải nghiệm Pro miễn phí"(Pro 무료 체험)와 "dùng thử miễn phí"(스토어 무료 체험)로 나눠 맞췄다. 웹 가이드가 인용하는 앱 메뉴 이름(Cài đặt điều khiển, Xem tiếp trên điện thoại, Thẻ)과 데모 리모컨 라벨을 앱 파일과 똑같이 맞췄고, 앱의 pairPhoneLimit에 남아 있던 영어 'Reset'은 확장 번역 라벨 "Đặt lại"로 바꿨다.

확인한 다른 교차 참조: 앱의 obAnimConnectPhone·obAnimScanCode·obAnimNewCode·obAnimRemoteConnected·obAnimYourPhones는 확장 라벨과 이미 똑같다. browsersDisconnectedBody는 확장 라벨을 인용하지 않는다. 웹 FAQ a7의 **Cài đặt**·**Đặt lại**, a5의 “Không kết nối được với trình duyệt”, contactBody의 **Thêm** → **Liên hệ**는 앱·확장 파일과 똑같다.

## 결정이 필요한 점

- **브라우저·OS 메뉴 이름(faq.a8, a9Steps, a10Steps, a10Note, a11Points, a13Points):** 베트남어 Chrome(“Đọc và thay đổi tất cả dữ liệu của bạn trên tất cả các trang web”, “Trên tất cả các trang web”, “Quyền truy cập trang web”), Safari(“Sửa trang web…”, “Khi truy cập các trang web khác”, “Luôn cho phép trên mọi trang web”), iOS·Android 설정 화면의 실제 명칭은 직접 확인하지 못해 원래 번역을 그대로 두었다. 베트남어로 설정한 기기에서 확인하기를 권한다.
- **remoteConnected "Đã kết nối điều khiển":** 베트남어에서 자연스러운 상태 표현("Đã kết nối tai nghe"와 같은 구조)이고, 앱 온보딩 애니메이션(obAnimRemoteConnected)과도 같아서 그대로 두었다.
- **FAQ 표기:** 웹 메뉴·버튼은 "FAQ"(nav.faq, helpCta), 앱과 FAQ 페이지 제목은 "Câu hỏi thường gặp"다. 앱이 "FAQ"를 메뉴 이름으로 인용하지는 않아서 그대로 두었다. 통일할지 결정이 필요하다.
- **A-B Loop:** 앱 결정을 따라 영어 "A-B Loop"를 유지했다(가이드 제목만 "Lặp đoạn (A-B Loop)").
