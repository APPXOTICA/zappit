# 중국어 간체(zh_Hans) 확장·웹 번역 검토 보고서

확장 번역은 대체로 자연스럽고 정확해서, 앱 온보딩 애니메이션(확장 팝업을 그린 화면)과 문구가 어긋난 2개만 고쳤다. 웹은 앱 검토에서 정한 용어(Pro 免费体验, 二维码, 定时关闭, 长按倍速, 区间循环, 在手机上继续观看, 从头播放)를 반영하지 않은 곳이 많아 앱과 같은 이름으로 맞췄고, FAQ의 Pro preview 설명에 있던 "无需绑定银行卡"(카드 등록 불필요 직역)를 없앴다. 앱에서는 확장 라벨을 인용하는 2개 키를 확장 번역에 맞췄다.

## 확인이 필요한 부분

- **landing.snack.speed**: 웹 소스 코드가 없어 {speed}의 실제 형식("1.5×"인지 "1.5"인지)을 확인하지 못했다. 배수 기호 없이 숫자만 들어간다면 "{speed} 倍速"가 더 자연스러우니 알려 주세요.
- **faq.a9Note "在所有网站上始终允许"**: Safari 중국어 간체 화면의 실제 메뉴 이름(예: "在每个网站上始终允许")을 직접 확인하지 못해 그대로 두었다. Mac Safari를 중국어로 바꿔 확인해 주세요. Chrome 관련 인용(读取和更改您在所有网站上的所有数据, 在所有网站上, 详情, 网站访问权限)도 같은 이유로 원본을 유지했다.
- **landing.title**: 앱 온보딩과 맞춰 "告别鼠标。"로 짧게 바꿨다. 기존처럼 "手机就是遥控器"까지 붙인 홈 헤드라인을 원하면 앱 obAnimTagline도 함께 바꿔야 한다.
- **faq.a1의 "无需绑定银行卡" 삭제**: 중국은 신용카드보다 위챗페이·알리페이가 일반적이라 "완전 무료, 자동 결제 없음"만 남겼다. 앱 proPreviewStarted와 같은 방향이다.
