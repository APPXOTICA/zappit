# 힌디어(hi) 확장·웹 번역 검토 결과

확장 6개, 웹 28개, 앱 교차 참조 1개를 고쳤어요. 웹에서 가장 큰 문제는 FAQ의 ‘Pro Preview’를 영어 그대로 둔 것과, 웹이 인용하는 앱 메뉴 이름(‘फ़ोन पर आगे देखें’, ‘ख़रीदारी वापस लाएँ’, 리플레이·음소거·구간 반복·프레임 버튼)이 앱 파일과 달랐던 점이에요. 확장은 직역한 ‘कनेक्टेड सूची’와 Reset 안내에서 무엇을 가리키는지 모호한 ‘इसे/यह’를 고쳤고, 앱의 pairPhoneLimit에 나오던 영어 ‘Reset’은 확장에 실제로 보이는 ‘रीसेट’로 바꿨어요.

## 확인이 필요한 부분

- **faq.a1 ‘연간 플랜의 무료 체험’:** 영어는 ‘유료 구독의 무료 체험’이에요. 무료 체험은 연간 구독에만 있어서 앱 trialReminderNotificationTitle과 같은 ‘सालाना प्लान का मुफ़्त ट्रायल’로 썼어요. 나중에 월간 구독에도 체험이 생기면 이 문구를 고쳐야 해요.
- **pairPhoneLimit에 ‘सेटिंग’ 추가:** 영어 원문에는 Settings가 없지만, Reset 버튼을 찾을 수 있게 넣었어요. 다른 언어도 같은 방식으로 맞출지 정해 주세요.
- **OS·브라우저 화면 문구(웹 FAQ a8~a13):** Chrome 권한 경고(‘सभी वेबसाइटों पर आपका सारा डेटा पढ़ें और बदलें’), Chrome 사이트 액세스 메뉴, Safari, iOS(‘सेटिंग्ज़’), Android(‘सेटिंग’, ‘ऐप्लिकेशन’, ‘अनुमतियां’) 라벨이 실제 힌디어 화면과 같은지 확인하지 못했어요(검색으로도 찾지 못함). 그래서 a8은 인용구를 그대로 두고 문장 구조만 고쳤어요. 실제 기기의 힌디어 화면으로 확인해야 해요.
- **확장 reset ‘रीसेट’:** 다른 버튼(‘डिसकनेक्ट करें’, ‘रद्द करें’)은 ‘-करें’ 형태지만 Reset만 명사형이에요. 자연스러워서 그대로 뒀어요. ‘रीसेट करें’로 바꾸면 웹 faq.a7과 앱 pairPhoneLimit도 함께 바꿔야 해요.
