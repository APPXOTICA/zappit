# 아랍어(ar) 확장·웹 번역 검토 결과

확장은 대체로 자연스러웠지만 Reset 설명이 "모든 폰을 재설정(초기화)"으로 읽혀 실제 결과인 "연결 끊기"로 고쳤고, 웹 FAQ가 Pro preview를 영어 "Pro Preview"로 두고 스토어 체험을 다른 말("الفترة التجريبية")로 불러 앱 용어("تجربة Pro المجانية" / "التجربة المجانية للاشتراك")로 맞췄습니다. 그 밖에 "열린 탭"을 "열린 표시"로 쓴 오역, "أضف إضافة" 반복, RTL에서 [ ] 괄호가 반전되어 보이는 문제, 앱과 다른 Replay 이름, 분(分) 복수형을 고쳤습니다. 앱은 확장 인용 버튼 이름 1개(pairPhoneLimit의 «Reset»)만 바꿨습니다.

확장 3개, 웹 24개, 앱 1개 수정. 검증(validate2.py ext:ar web:ar, validate.py ar): 누락·추가 키, placeholder 문제 없음. extDescription 49자.

## 결정이 필요한 점

- **[ ] 괄호 표시(hint3, f4Body):** RTL 문단에서 `[`와 `]`는 유니코드 규칙상 거울처럼 바뀌어 보입니다. 보이지 않는 LTR 격리 문자(U+2066 … U+2069)로 감쌌습니다. 사이트에서 괄호가 리모컨 버튼 모양과 같게 보이는지 실제 화면으로 확인해 주세요. 다른 RTL 언어가 생기면 같은 처리가 필요합니다.
- **Sleep Timer 스낵바:** 웹은 plural을 지원하지 않아 "{min} دقيقة"가 3~10분일 때 틀립니다. 앱 minutesShort와 같은 약어 "{min} د"로 바꿨습니다. 웹에 plural 지원을 넣으면 앱 minutesCount처럼 풀어 쓸 수 있습니다.
- **Reset 설명:** 버튼 이름은 "إعادة الضبط"(재설정)을 유지하고, 설명·확인창·FAQ는 "연결이 끊어진다"로 썼습니다. "재설정"만으로는 폰·브라우저 자체를 초기화한다고 오해할 수 있어서입니다. 버튼 이름도 "إعادة ضبط الاتصالات"처럼 바꿀지 정해 주세요(바꾸면 앱 pairPhoneLimit·웹 a7도 함께 바꿔야 함).
- **f3Tip "top right":** 원본 번역이 "오른쪽"을 빼고 "أعلى جهاز التحكم"(위쪽)으로만 썼습니다. 앱이 RTL에서 좌우 반전되면 버튼이 왼쪽 위에 있으므로 그대로 두었습니다. 실제 아랍어 화면에서 위치를 확인해 주세요.
- **Chrome·Safari 화면 문구(a8, a9Steps, a10Steps, a10Note):** 브라우저의 아랍어 공식 메뉴 이름과 같은지 확인하지 못해 고치지 않았습니다.
