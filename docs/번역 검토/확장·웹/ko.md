# 한국어(ko) 확장·웹 번역 검토 보고서

확장 문구 32개와 웹 문구 205개를 영어 원문과 검토된 앱 번역(intl_ko.arb)에 맞춰 확인하고, 확장 5개, 웹 63개, 앱 교차 참조 2개를 고쳤어요. 웹은 대부분 -ㅂ니다체여서 앱(웹뷰로 같이 보임)과 같은 -요체로 통일했고, "Pro Preview"를 앱 용어 "Pro 무료 체험"으로, "A-B Loop"·"FAQ"·"폰에서 이어보기"처럼 앱 메뉴 이름과 어긋난 인용을 앱과 똑같이 맞췄어요. 앱의 ‘Reset’ 안내는 확장의 번역 라벨 ‘초기화’로 바꿨어요.

- 교차 참조 라벨: 웹의 **설정**·**초기화**는 확장 settings·reset과, 리모컨 설정·길게 누르기 속도·구간 반복 횟수·폰에서 이어 보기·구매 복원·더보기·문의하기·자주 묻는 질문·브라우저에 연결할 수 없어요는 앱 파일과 글자 그대로 같아요. 앱 obAnim* 문구(리모컨 연결됨, 내 폰, {time} 후 새 코드, 폰의 Zappit 앱으로 이 코드를 스캔하세요.)는 확장과 같아요.
- 웹의 "누르세요"는 폰(앱) 동작에만 남기고 컴퓨터 동작은 "클릭"으로 통일했어요.
- 확장 placeholder `$TIME$`와 placeholders 객체, 웹 `{a}`·`{b}`·`{browser}` 등, 배열 길이, `**` 마크업은 그대로예요. extDescription은 27자예요.

## 소유자 결정이 필요한 점

- **웹 말투(-요체 전환):** 지시대로 웹 전체를 -요체로 바꿨어요(약 45개 문구). 법적 문구인 footer.trademark까지 -요체로 바꿨는데, 이 줄만 -ㅂ니다체로 둘지 정해 주세요.
- **Chrome·Safari 화면 문구 인용(faq.a8~a13):** "모든 웹사이트에서 내 데이터 읽기 및 변경", "사이트 데이터를 읽고 변경할 수 있음", "웹사이트 편집…", "다른 웹사이트 방문 시", "모든 웹사이트에서 항상 허용" 등은 원본 번역을 유지했어요. 실제 한국어 Chrome·Safari 화면과 글자 그대로 같은지 원본 화면에서 확인하지 못했어요. 한 번 실제 화면과 대조해 주세요.
- **pairPhoneLimit:** 소유자가 고친 문장에 ‘설정’의 위치를 더했어요. 원래처럼 ‘초기화’만 쓰길 원하면 "컴퓨터의 Zappit 확장 프로그램에서 ‘초기화’를 하세요."로 바꾸면 돼요.
- **FAQ 이름:** 웹 메뉴·제목을 앱과 같은 "자주 묻는 질문"으로 바꿨어요. 웹 상단 메뉴가 길어 보이면 웹만 "FAQ"로 두는 방법도 있지만, 그러면 앱 웹뷰에서 이름이 달라져요.
- **landing.snack.speed("{speed} 속도"):** 앱에 같은 알림 문구가 없어 그대로 두었어요. 앱에서 배속 알림 표기를 정하면 맞춰 주세요.
