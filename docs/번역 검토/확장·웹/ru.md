# 러시아어(ru) 확장·웹 번역 검토 결과

확장 번역은 대체로 자연스러웠지만, 'Сбросить телефоны'(폰을 초기화한다로 읽힘)와 폰 목록의 성 불일치('Подключено')를 고쳤다. 웹은 Pro preview를 앱 용어 'Бесплатный доступ к Pro'로 바꾸고, 앱 메뉴 이름(«Настройки пульта», «Вопросы и ответы», «Смотреть сначала», «Покадрово», «Восстановить покупки»)과 확장 버튼 이름(**Настройки**, **Сбросить**)에 맞췄으며, 타임라인과 프레임 다이얼이 모두 'шкала'라 헷갈리던 부분을 'линейка'로 나눴다. 앱은 확장 버튼을 영어 «Reset»으로 인용하던 `pairPhoneLimit` 하나를 확장 번역 «Сбросить»에 맞췄다. 말투(вы)는 앱과 같게 유지했다.

## 확인이 필요한 점

- **타사 UI 문구 검증 못 함**: Chrome 권한 경고('Просмотр и изменение ваших данных на всех сайтах'), Chrome 사이트 접근 메뉴('Может просматривать и изменять данные сайтов', 'На всех сайтах', 'Подробнее', 'Доступ к сайтам'), Safari('Редактировать веб-сайты…', 'При посещении других веб-сайтов', 'Всегда разрешать на всех веб-сайтах'), iPhone 설정 경로 '**Программы**'(iOS 18 러시아어가 'Программы'인지 'Приложения'인지)는 이번에 공식 화면이나 도움말과 대조하지 못했다(웹 조회 한도 초과). 원본을 그대로 두었으니 실제 러시아어 Chrome·Safari·iOS 화면에서 한 번 확인이 필요하다.
- **Guide 이름**: 앱의 Tutorial 메뉴는 'Инструкция'인데 웹 가이드 제목·메뉴는 'Руководство'다. 앱에서 이 메뉴를 누르면 웹 가이드가 열리므로 한쪽으로 맞출지 결정이 필요하다(지금은 둘 다 그대로 둠).
- **'линейка'**: 프레임 다이얼 이름을 'линейка'(눈금 자)로 정했다. 앱에 이 다이얼의 별도 이름이 생기면 웹도 같은 단어로 맞춰야 한다.
- **faq.a1의 'экран покупки'**: 앱 Pro 화면에 따로 이름이 없어 '구매 화면'으로 두었다.
