# 번체 중국어(zh_Hant) 번역 검토 보고서

전체적으로 자연스러운 대만식 번역이었지만, 결제 문구에 사용자가 모르는 "商店/商店帳戶"(스토어/스토어 계정)가 반복되고, Pro preview를 "Pro 體驗"이라고만 써서 "Pro 경험"으로도 읽히고 무료라는 점이 드러나지 않았다. 또한 "歡迎使用", "感謝試用"(스토어 체험 용어 "試用" 사용), "不需要信用卡" 같은 영어식 직역과, 폰에서 보이는 "此頁面/此畫面"처럼 대상이 모호한 표현, 대만 표준이 아닌 "帳戶"(→ 帳號)를 고쳤다.

## 확인이 필요한 사항

- **Pro preview 용어:** "Pro 免費體驗"(무료 체험)과 스토어의 "免費試用"(무료 체험판)으로 나눴다. 대만 앱에서 둘 다 흔한 표현이며 단어 자체가 달라 혼동 위험은 낮지만, 웹 번역(`zappit_web/src/lib/i18n/messages/`)에 "Pro 體驗"이 쓰였다면 같이 맞춰야 한다.
- **cancelAnytime:** "訂閱管理"(구독 관리)는 App Store·Google Play의 구독 관리 화면을 가리키는 일반 표현으로 골랐다. 앱 안의 "管理訂閱" 버튼과 연결해 읽힐 수 있는데, 실제로 그 버튼이 스토어 구독 관리(Customer Center)로 이어지므로 의미상 문제는 없다고 판단했다.
- **YouTube 메뉴 이름(ytYou "個人", ytHype "Hype", ytHistory "觀看記錄"):** YouTube 대만 화면의 실제 명칭을 직접 확인하지 못해 그대로 두었다. 출시 전 YouTube(zh-TW)에서 확인을 권장한다.
- 메뉴·버튼 이름은 바꾸지 않았다(menu-name 변경 없음).
